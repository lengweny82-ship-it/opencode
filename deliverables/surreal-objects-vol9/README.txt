TECHNICAL NOTES
Sources were generated at 1024 x 1024, except image 05 at 1408 x 768. Artwork was cropped and fitted to a square without stretching, then enlarged using Lanczos interpolation. This is not native 7000px detail or AI super-resolution.
RGB colors use 32 levels per channel for file-size control; alpha remains 8-bit.
manifest.json lists PNG sizes and SHA-256 hashes. transparency-checks.json records interior background removal checks.
