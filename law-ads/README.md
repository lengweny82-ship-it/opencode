- **مكتب الأستاذ أحمد عبد النبي** للمحاماة والاستشارات القانونية — مصر، القاهرة

- للتواصل والاستشارات: **0106 244 5777**

## الملفات

- `index.html` — صفحة المعرض (عرض وتحميل كل التصاميم)
- `exports/*.png` — نسخ بجودة طباعة 2160×2700
- `exports/*.jpg` — نسخ جاهزة للنشر على السوشيال ميديا
- `exports/thumb/*.jpg` — مصغّرات المعرض
- `posters-a.html` / `posters-b.html` — ملفات التصميم القابلة للتعديل (الإعلانات ١–٥ و ٦–١٠)
- `assets/css/style.css` — نظام التصميم (الألوان والخطوط والمكوّنات)
- `assets/img/` — الصور المستخدمة (بما فيها صورة المحامي المقصوصة من الإعلان الأصلي)

## التعديل وإعادة التصدير

```bash
npm install          # مرة واحدة
node scripts/render.js   # تصدير كل التصاميم من جديد إلى exports/
```

لتغيير أي نص (رقم الهاتف مثلًا): عدّله في `posters-a.html` و`posters-b.html` ثم أعد التصدير.
الأبعاد 1080×1350 (تُصدَّر بضعف الدقة 2160×2700).
